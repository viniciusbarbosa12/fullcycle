## Como usar

- Cada pasta tem um `readme.md` com o mapa do curso.
- `modules/` guarda as fases de estudo.
- `labs/` guarda os exercicios praticos.
- `examples/` guarda exemplos de referencia.
- `final-project/` guarda o desafio ou projeto final do curso.

## Regra de estudo

O foco e aprender praticando: tentar primeiro, revisar depois, corrigir os pontos fracos e so consultar exemplos prontos depois da tentativa.
