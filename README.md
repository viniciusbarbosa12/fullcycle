## How to use

- Each folder has one `readme.md` with the course map.
- `modules/` keeps the study phases.
- `labs/` stores the practical exercises.
- `examples/` stores reference examples.
- `final-project/` keeps the challenge or final project of the course.

## Study Rule

The focus is learning by practicing: try first, review later, correct weak spots, and only consult ready examples after the attempt.
