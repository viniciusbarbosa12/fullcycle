# Phase 8: Dashboards and alerts in Grafana

## Lessons

- Creating dashboard using Gauge
- Adding Counter Panel
- Histogram panel
- Configuring alert in Grafana
- Triggering alerts

## Objective

Transform metrics into useful panels and alerts.

Pretty Dashboard that nobody wears is digital decoration. The focus here is to create panels that help answer questions and alerts that warn real problems without turning into a bakery siren.

## Main concepts

- Dashboard
- Panel
- Query PromQL
- Gauge panel
- Counter panel
- Histogram panel
- Alert rule
- Threhold
- Notification
- Alarm
- False positive
- Severity
- Runbook
- Basic SLO

## Practical exercises

- Create Dashboard for Gauge.
- Create Counter Panel.
- Create Histogram Panel.
- Create metric-based alert.
- Fire alert on purpose.
- Adjust Threshold.
- Create a mini runbook telling you what to do when the alert goes off.
- Documenting which alerts make sense and what noise would be.

## Reflection questions

- Which makes a dashboard useful?
- When an alert is really needed?
- What's false positive?
- What is the risk of too much alertness?
- Why Every Alert Should Have Clear Action?
- How would I choose threshold?
- What warning would I create for high latency??
- Which alert would I create for 5xx error?

## Checkpoint

Have dashboard and alert working, with a simple runbook explaining how to react.
